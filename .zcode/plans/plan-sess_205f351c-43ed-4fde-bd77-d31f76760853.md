# TUI 视觉改造：去外框 → 柔和背景色 + 间隔统一

## 设计基调（参考 pi 上游 dark 主题）

pi 最新版的工具卡片就是背景色方案（`toolPendingBg / toolSuccessBg / toolErrorBg`），本次对齐其色值（实现时用 Ottosson okhsl→sRGB 换算钉死 hex，约 24–25% 亮度的暗黑柔和色）：

| 角色 | pi 原值 (okhsl) | 用途 |
|---|---|---|
| `tool_pending_bg` | okhsl(229 5% 24%) 中性暗蓝灰 | 工具运行中卡片背景 |
| `tool_success_bg` | okhsl(158 46% 25%) 柔和暗绿 | 工具/bash 成功背景 |
| `tool_error_bg` | okhsl(19 54% 25%) 柔和暗红 | 工具/bash 失败背景 |
| `plan_bg` | okhsl(295 42% 24%) 柔和暗紫（pi customMessageBg） | 计划模式卡片背景 |

16 色 ANSI 降级：`dark_ansi()` 用命名色近似（pending/plan 用 `DarkGray`，success 用 `Green`，error 用 `Red` 作 bg）；external 主题用现有 `blend_rgb`（bg 与 green/red 低比例混色）推导。

## 改动清单

### 1. 主题角色（crates/latent-tui/src/theme/）
- `mod.rs`：`Theme` 结构体新增 `tool_pending_bg / tool_success_bg / tool_error_bg / plan_bg` 四个 bg 角色；删除不再使用的 `assistant_border`。
- `builtin.rs`：`dark()`（真彩）填上表 hex；`dark_ansi()` 填 ANSI 命名色。
- `external.rs`：为外部主题推导四个新角色。

### 2. 工具/bash 卡片：边框 → 背景色块（crates/latent-tui/src/tool_card.rs）
- 新增共享原语 `bg_block(lines, width, bg)`：每行内容 + 行尾补齐空格铺满整行 bg（复用 `user_block` 的"整行铺背景无缝隙"手法），替代 `box_around`（删除之，含其测试）。
- `tool_box_top`：去掉 `╭─╮` 顶边与 `│ │` 侧边；`⏺ name args` 行整行铺状态对应 bg，`⏺` 保留状态色前景（黄/绿/红），工具名/参数前景色不变。
- `tool_box_bottom`：输出行整行铺 `tool_success_bg`/`tool_error_bg`（无底边框），折叠提示行同 bg。
- `bash_box`：同 `tool_box_*` 处理。
- ToolCall 提交 Pending、结果到达后按最终状态重提交（handlers.rs 现有机制不变），卡片背景随状态绿/红切换。

### 3. 模型消息去框（crates/latent-cli/src/modes/interactive/）
- `view.rs` `render_item` 的 `Assistant { boxed }`：无论 boxed 与否一律裸 markdown 渲染（无框无背景）；从 `state.rs` 的 `TranscriptItem::Assistant` 删除 `boxed` 字段，`handlers.rs` 同步清理。
- Plan 卡片：标题行（黄粗体）与引导行保留，正文改铺 `plan_bg` 紫色背景块（用 `bg_block`）。
- markdown 代码块自带的 muted 色边框**保留**（属 markdown 渲染，非消息外框）。

### 4. tokens 用量外框删除（crates/latent-cli/src/modes/interactive/usage.rs）
- `usage_block` 去掉 `╭── tokens ╮` 三行外框，直接落盘单行用量行（`footer::turn_usage_line` 原样，左对齐）；`handlers.rs` 的 `usage_item_of` 同步。

### 5. 间隔统一 3 行（方案 B）+ 消息间至少 1 行空白
- `view.rs` `viewport()`：在状态行之后、补全弹窗/编辑器之前**固定插入 1 行空白**（视口高度恒定 +1 行）。效果：
  - 生成中：输入框上方恒为「预览 1 行 + 状态行 + 空行」，至少 1 行空白隔开输入框，实时预览保留；
  - 完成后：turn-end 空带 1 + 状态行 1 + 固定空行 1 = 3 行空白；
  - 更新 L14–19 守恒律注释与 `mod.rs` render_tick 注释（空带 1 行的说明仍成立）。
- 消息间隔（`handlers.rs` 提交路径 + `state.rs` `commit_blank` 去重已有）：外框删除后，每个消息组起始前补 `commit_blank()`（去重防双空行）：User、Thinking、Assistant、ToolCall（Call 与 Result 同卡片，中间不加）、Bash 卡；用量行紧贴正文不变，下一组起始的空白自然隔开。
- 全文重绘路径 `render_transcript` 无需改（Blank 是转录条目，自动一致）。

## 测试与验收
- 单测更新：`tool_card.rs`（框断言 → bg 断言）、`view.rs`（`│ yo` 类断言、`viewport_layout_shape`/popup 等高度与行号 +1）、`usage.rs`、`footer.rs` 相关断言。
- 硬门槛：`cargo build --workspace` + `cargo test --workspace` + `cargo clippy --workspace --all-targets` 全绿零警告。
- E2E：`cargo build --bin latent && cd tests/e2e && pytest -v`（重点回归 tool_roundtrip / bash_tool / ctrl_o / output_display / plan_mode；断言剥 ANSI 不依赖边框字符，如有场景依赖 `╭` 需同步修正）。
