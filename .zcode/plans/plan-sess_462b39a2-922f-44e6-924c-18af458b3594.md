## 目标(按你的独立模型)

平行子 agent 会话与主会话的会话历史**互相不可见、各自管理**:

- 主会话 `/session list`:维持现状(只列无 tag 的主会话文件,已排除子会话文件)。
- 子会话 `/session list`:列出**该 agent 自己的历史文件**(`<时间>__<agent名>__<id>.jsonl`,tag 匹配当前 agent 名),选中后在该子会话上恢复——落盘重定向到子会话**自己的**句柄,主会话的全局 holder 全程不动。

## 实现步骤

### 1. 作废上一轮错误方向的改动
`git checkout crates/latent-cli/src/modes/interactive/handlers.rs`(恢复被拦截的原始版本,再在其上做下述改动)。

### 2. latent-session:按 tag 列举子会话谱系(`manager.rs`)
新增 `list_session_files_with_tag(dir, cwd, tag) -> Vec<SessionSummary>`:复用 `list_session_files` 的遍历/排序/预览逻辑,只收文件名形如 `<时间>__<tag>__<id>.jsonl` 且中间段 == `sanitize_session_tag(tag)` 的文件。`consider_session_file` 加一个枚举参数区分"主谱系(排除带 tag)/指定 tag"两种模式。
附单元测试:主列表不含 tag 文件、tag 列表只含匹配 tag 的文件。

### 3. assembly:暴露子会话各自的落盘句柄
`child_store_factory` 闭包里本来就会为每个子会话创建私有 `SessionManagerHolder`(埋在 sink 里)——把它登记进一个共享注册表 `ChildStoreRegistry = Arc<Mutex<HashMap<String, SessionManagerHolder>>>`(key = tag/agent 名),经 `BuiltSession` 新字段暴露。不改 ChildStore/工厂签名,latent-core 零改动。

### 4. handlers.rs:按谱系接线
- `InteractiveCtx` 增加可选的 `child_stores: Option<&ChildStoreRegistry>`(测试传 None)。
- `open_session_selector`:子会话分支——按 `active_agent` 名查注册表得 holder,用其当前文件所在目录 `list_session_files_with_tag`,预选当前文件;列表为空提示"没有 {agent} 的历史会话"。删除原来那道拦截警告。
- `switch_to_session`:子会话分支——`switch_resume_session(&ctx.session.current(), &子会话holder, file)`(该函数本身 holder 无关,直接复用;不 abort_all、不碰主会话、不做路由切换),之后照常清屏回放。主会话分支维持现状。
- 顺手修 `/new` 在子会话下的真 bug:现在只是内存 reset 但仍往同一个文件追加,文件里两段会话混成一条谱系;改为查到 holder 时走 `switch_new_session`(加 `tag: Option<&str>` 参数,子会话传 agent 名)真正开新文件,查不到(纯内存)才原地 reset。

### 5. 测试
- interactive tests:子会话内恢复后,新写入进被恢复的文件、子会话旧文件与主会话文件均不变;`switch_new_session` 带 tag 的文件名断言。
- E2E 新场景:第一次运行(主会话问答 → /subagent → 子会话问答 → 退出);第二次运行(/subagent → /session list 列出该 agent 的上次会话 → 回车恢复 → 历史回放上屏、续聊上下文断言)。
- 硬门槛:`cargo test --workspace` + `cargo clippy --workspace --all-targets` 全绿,受影响 E2E 用例通过。

### 不改的东西
- 主会话的 `/session list`、`/session info`、审批/沙箱逻辑一律不动。
- task 工具后台子 agent(run id 为 tag)不属于用户可切换谱系,不在列表展示范围。
