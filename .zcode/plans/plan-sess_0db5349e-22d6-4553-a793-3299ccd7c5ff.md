## 最小改动：原文保留，跨工具引用改为"条件生效"

原则：所有提示词原文一字不改；唯一的问题是"指向其他工具"的句子在对方未激活时是逻辑错误 —— 把这几句移入**条件路由表**：只有被引用的工具也在激活集里才注入系统提示词，原样输出。

### 改动

1. **bash**（bash.rs）：guidelines 只留原文 `Avoid interactive commands; they will hang until timeout.`；`Prefer read for inspecting files; use bash for searches, git, builds and quick scripts.` 移入路由表（条件：read+bash 都激活）。
2. **powershell**（bash.rs）：同上，`Prefer read ... use powershell ...` 移入路由表（条件：read+powershell）。
3. **write**（write.rs）：guidelines 整条移入路由表（条件：edit+write 都激活，原文 `Use write only for new files or complete rewrites; prefer edit for partial changes.`）；description 仅删去结尾 `; use edit for partial changes`（tools 字段无法按激活集变化，其余原文保留）→ `Write a file to the local filesystem. Use write only for new files or complete rewrites.`
4. **read / edit**：原文无跨工具引用，完全不动。
5. **新增** `latent_tools::routing_guidelines(active: &[&str]) -> Vec<String>` 纯函数（规则所需工具全部在激活集内才输出，原文照抄）；cli `build_session` 按实际激活集调用，结果进 `SystemPromptOptions.prompt_guidelines`（`<rules>` 节）。

### 效果示例

- 你现在只开 bash：模型看到 `Avoid interactive commands...`，**不再出现** "Prefer read..."；
- 四个全开：所有原文规则照旧出现，和现在完全一样。
