# 会话恢复与切换：`rpi -r` / `rpi -l` / TUI `/session`

## 现状
`--continue`/`-c` 已完整打通"找最近会话文件 → 加载 → seed_messages 回填 → TUI 回放 → 续写"链路（main.rs:292 `resolve_session_store` → assembly.rs:908-958）。本方案在此基础上加三个入口：`-r`（= 最新会话续聊，`-c` 的别名）、`-l`（列出历史会话 + 可按序号 resume）、TUI 内 `/session` 扩展（无参弹历史会话列表选择切换，`/session info` 保留原信息展示）。

## 改动

### 1. crates/rpi-session/src/manager.rs — 新增会话列表 API
- `pub struct SessionSummary { path, modified: SystemTime, session_id, preview: String }`
- `pub fn list_session_files(dir, cwd: Option<&str>) -> Vec<SessionSummary>`：按 mtime 倒序列出候选会话（复用 `find_latest_session_file` 的扫描与 `consider_session_file` 的过滤逻辑——排除 tag 子会话、cwd 匹配；重构 `find_latest_session_file` 为取列表首项）。`preview` = 流式读文件遇到的第一条 user 消息文本截 80 字符单行（无则 "(空会话)"）。
- 单测加在 `session_tree_and_compaction.rs`：多文件排序、tag 文件排除、cwd 过滤、preview 截取。

### 2. crates/rpi-cli/src/main.rs — CLI 入口
- `parse_args`：`"--continue" | "-c" | "-r" | "--resume"` → resume 模式；其后紧跟的纯数字参数消费为 `resume_index`（1 起，对应 `-l` 列表序号，缺省 1 = 最新）。新增 `-l`/`--list` → `list: bool`。
- `resolve_session_store(cont, resume_index)`：resume 时改用 `list_session_files` 取第 `resume_index` 项（越界报错并提示先 `rpi -l` 查看），找不到会话报错文案不变。
- `-l` 在 `run()` 模式分发前独立处理：打印表格（序号 / 本地时间 / session id 前 8 位 / 消息预览 / 文件路径）后退出 0；无 HOME 报错。
- `print_help` 与文件头用法注释补 `-r`/`-l` 两行。

### 3. crates/rpi-cli/src/assembly.rs — 运行期切回历史会话
- 新增 `pub async fn switch_resume_session(session: &AgentSession, holder: &SessionManagerHolder, file: &Path) -> Result<Option<PathBuf>, String>`，镜像 `switch_new_session`（assembly.rs:356）与 build 期 resume 路径（assembly.rs:942-958）的语义：
  1. `rpi_session::create_session(Some(file))` 加载既有文件续写（append-only，同一文件继续追加）；
  2. `holder.set` → `agent().reset()`；
  3. `build_session_context(&manager.branch_entries(), leaf)` 得 seed_messages / thinking / active_tools / mode → `agent().set_messages(seed)`、`set_thinking_level`、`set_active_tools_by_name`（非空时）、`set_mode`（持久 ModeSection，符合 append-only 不变量）；
  4. 返回文件路径。

### 4. crates/rpi-cli/src/modes/slash.rs — `/session` 扩展
- `COMMANDS` 中 `/session`：`args: "[info]"`，description 改为"切换历史会话；info = 显示当前会话信息"。
- 新增 `SESSION_VARIANTS: &[("info", "显示当前会话信息与统计")]`，`popup_entries` 挂 variants（同 `/mode` 先例）。
- `SlashAction::Session` → `Session { arg: Option<String> }`，parse 传参。

### 5. crates/rpi-cli/src/modes/interactive/{state.rs, handlers.rs} — TUI 交互
- `SelectKind` 新增 `Session { files: Vec<rpi_session::SessionSummary> }`。
- `execute_command` 的 Session 分支：
  - `Some("info")` → 现有 `session_info_lines` 原样展示；
  - `Some(其他)` → 未知参数警告；
  - `None` → 流式拒绝（同 `/new` handlers.rs:615）+ 仅主会话（`is_main`）；会话目录取当前 manager 的 `file_path().parent()`，无 manager 时用 `~/.rpi/sessions`；`list_session_files(dir, Some(cwd))`，空 → 警告"没有历史会话"；否则 `SelectList`（条目格式 `MM-dd HH:MM  <preview>`，当前文件置中选中）弹 `SelectKind::Session`。
- `handle_select_key` Enter 分支：`SelectKind::Session` → `registry.abort_all()`（同 /new）→ `switch_resume_session` 成功后 `state.reset_for_new_session()` → `replay_history(ctx, state)`（复用启动回放）→ `refresh_footer` → ephemeral 提示 `resumed session: <path>`；失败 error_line。Esc 无操作。

### 6. 测试
- Rust：`interactive/tests.rs` 加装配级测试——建会话写消息 → `/new` 切走 → `switch_resume_session` 切回 → 断言 agent messages 恢复、新 append 落回同一文件；slash parse 测试补 `/session`、`/session info`。
- E2E 新建 `tests/e2e/test_session_resume.py`（harness 已支持 `extra_args`）：
  - `-r` 续聊：启动 → mock 对话一轮 → quit → 带 `extra_args=["-r"]` 重启 → `expect_text` 断言历史消息已回放；
  - `/session` 切换：对话一轮 → `/new` → `/session` 弹列表 → Enter 选中旧会话 → 断言旧转录回放上屏。

### 不碰的东西
- `--continue`/`-c` 语义不变；`/session info` 输出不变；print/json/rpc 模式不受影响（`-l` 为独立早期分支）。
