## 目标

给所有模态选择器/弹窗加上与 `/` 命令弹窗同款的圆角外框，使其与上方滚走的转录内容在视觉上分离。涉及：`/setting`、`/model`（含添加模型的写入位置/api 协议子选择器）、`/thinking`、`/theme`、`/subagent`、`/session list`、审批弹窗、扩展 Confirm/Select——它们全部经过 `crates/latent-cli/src/modes/interactive/view.rs:262-267` 这一个渲染点，改动集中；「添加模型」表单信息区（view.rs:216-251）也无框，一并处理。

## 改动

### 1. latent-tui 新增 `src/popup.rs`：共享画框辅助
- `pub fn frame(content: Vec<Line<'static>>, width: usize, theme: &Theme) -> Vec<Line<'static>>`
- 画法与 `CommandPopup::render`（command_popup.rs:154-188）现行完全一致：顶 `╭` + `─`×(width−2)、底 `╰` + `─`×(width−2)、内容行 `│ ` + 内容 + ` │`，内容截断到内宽（width−4）并右侧补空格对齐；边框色 `theme.popup_border`、透明背景；在 `lib.rs` 导出。
- 附单测：框结构、超宽截断、CJK 双宽补齐。

### 2. CommandPopup / FilePopup 去重
两者画框代码逐字相同，改为构建内容行后调用 `popup::frame`（内容对齐逻辑不动），三份重复边框代码归一，现有单测（如 `render_is_boxed_with_selected_marker`）保证视觉不变。

### 3. view.rs 选择器槽与表单槽加框（核心）
- 选择器槽：`select.prompt` 先按 `\n` 拆成多行 accent+bold（顺手修复审批弹窗 prompt 含字面换行被当单行渲染的帧对齐隐患），下方接 `SelectList::render`（传内宽），整体包 `popup::frame`。
- 表单槽：「模型信息」标题 + 字段行 +（select 未激活时的）问题行，整体包 `popup::frame`；select 激活时呈现「表单信息面板 + 选择器面板」两块堆叠。

### 4. 测试与门槛
- view.rs 补测试：选择器激活时首行 `╭`/末行 `╰`、prompt 与选项在框内、多行 prompt 正确拆行、表单区有框；现有 `viewport_modal_ui_keeps_preview_pinned` 等只断言 preview_window/scroll_extra，不受影响。
- 硬门槛：`cargo test --workspace` 全绿 + `cargo clippy --workspace --all-targets` 零警告。
- E2E：跑 `tests/e2e` pytest（重点 plan_mode 审批流、slash_commands、theme、session_resume）；expect_text 剥 ANSI 且忽略空白、框字符独立成行，现有断言预计不受影响，个别跨行 pattern 如受影响再微调。
