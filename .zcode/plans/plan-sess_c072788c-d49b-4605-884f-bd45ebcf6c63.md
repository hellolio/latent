# 实现 Skill 功能（pi 风格）

## 设计要点

- **skill 信息唯一出口 = load_skill 工具声明**：`description()` 动态渲染固定说明句 + skill 清单（`- {name}: {description}`）。随工具声明每轮请求发给模型，主会话与勾选了该工具的子 agent 一视同仁。不加 `<skills>` 系统提示词节。
- 子 agent 加载能力 = 定义 md `tools:` 白名单是否含 `load_skill`；默认只读集不含。

## 1. 新模块 `crates/rpi-core/src/skills/`（仿 subagent 模式）

**`defs.rs` — 发现与解析**
- `SkillDef { name: String, description: String, path: PathBuf }`。
- `discover_skill_defs(cwd, home) -> (Vec<SkillDef>, Vec<String>)`：扫描 `<cwd>/.rpi/skills/*/SKILL.md` 与 `~/.rpi/skills/*/SKILL.md`（先用户后项目，BTreeMap 按名去重，项目覆盖用户）；name 取 frontmatter `name`，缺省回退目录名；description 取 frontmatter `description`（必填，缺失诊断跳过）。解析失败单条诊断跳过。
- 复用 `subagent/defs.rs` 的 `split_frontmatter`（改为 `pub(crate)`），不引入 YAML crate。

**`tool.rs` — load_skill 工具**
- `LoadSkillTool` + `LoadSkillDeps { skills: Vec<SkillDef> }`（DI）。
- `name() = "load_skill"`；schema 单参数 `skill`（string，必填）。
- `description()`：固定说明句（何时该用、加载后按 skill 指引行动）+ 从 `deps.skills` 拼的清单。
- `execute`：按名查表；未知名 → `ToolError::Failed` 并列出可用名。命中 → **调用时**读文件全文（非启动缓存，中途修改生效），`ToolOutput::text(正文)`；读失败 → `ToolError::Failed`。
- `prompt_snippet()`：一行固定摘要（同其他工具模式）。
- `mod.rs` + `lib.rs` re-export。

## 2. 装配 `crates/rpi-cli/src/assembly.rs`

- subagent 发现块（~917 行）旁：`discover_skill_defs(&cwd, home)` + `eprintln!("[rpi][skills] {diagnostic}")`。
- `tools.push(LoadSkillTool)`，**必须在 subagent 装配（~983 行 `tool_pool: tools.clone()`）之前**，使 tool_pool 含 load_skill 供子 agent 定义勾选；`read_only_tools` 默认集不变。
- 不改 `SystemPromptOptions`（无 `<skills>` 节）。

## 3. 测试

- defs 单测：frontmatter 解析（name 覆盖目录名、description 缺失诊断）、项目覆盖用户、无 SKILL.md 的目录跳过。
- tool 单测：已知名返回正文、未知名报错且列出可用名、description 含 skill 清单。
