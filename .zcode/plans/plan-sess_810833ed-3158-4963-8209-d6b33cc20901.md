# 添加模型表单 UI 修正（view.rs + state.rs 小改）

## 现状问题
1. **重复**：api 协议选择列表弹出时，选择器 prompt（"添加模型 · 选择 api 协议"）和表单问题行（"添加模型 · api 协议"）同时渲染。
2. **顺序颠倒**：表单信息块渲染在 preview（选择列表所在区）之后，导致"已配置摘要"显示在选择选项下面。
3. apiKey 步骤提示文案没说明可直接粘贴密钥。

## 改动

### 1. `crates/rpi-cli/src/modes/interactive/view.rs`
把表单信息块移到 preview 块**之前**，并调整顺序 + 去重：
```
已配置摘要（form.summary()，随进度变长）   ← 上
当前问题行（form.question()）
[选择列表 / 编辑器]                        ← 选项在下
```
- 问题行在 `state.select.is_some()` 时跳过（此时选择器 prompt 就是问题，消除重复）；摘要始终显示。
- 修改后的结构：`if let Some(form) = &state.model_form { 摘要行 → (select 为空时)问题行 }`，置于 `let mut preview` 构建之前。

### 2. `crates/rpi-cli/src/modes/interactive/state.rs`
`ModelForm::question()` 的 ApiKeyEnv 分支文案改为：
`"添加模型 · apiKey(输入环境变量名,或直接粘贴密钥;留空跳过)"`

## 验证
- `cargo test -p rpi-cli`（现有 4 个表单单测不依赖布局顺序，应全绿）+ clippy。
- 手工/观察验证走现有 E2E `test_model_config.py`（不含表单视图断言，回归即可）。
